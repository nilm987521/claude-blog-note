# 你應該用哪個 Claude 模型來開發？

**文章網址：** https://claude.dev/blog/which-claude-model-should-you-build-with/

## 重點摘要

> **注意：** 此文章發布於 claude.dev，該網域在本執行環境中無法存取，以下摘要根據標題及相關公告資訊整理。

1. **選型指引背景**：隨著 Claude Fable 5.2 與 Mythos 5.2 的發布，Claude 模型家族進一步擴大，本文旨在協助開發者根據使用場景選擇最合適的模型。

2. **模型家族概況**：目前 Claude 模型包括 Haiku 5.5（速度最快、成本最低）、Sonnet 4.6（平衡性能與成本）、Opus 5.5（適合日常複雜任務）以及 Fable 5.2（適合高難度技術工作）。

3. **Anthropic 的建議**：根據 Fable 5.2 發布公告，Anthropic 建議日常任務仍以 Opus 5.5 為主，較複雜或開放性的技術工作（如程式設計、科學研究、工程任務）再切換到 Fable 或 Mythos。

4. **成本與效能取捨**：Fable 5.2 定價（輸入 $8/M token、輸出 $40/M token）高於 Opus 5.5，開發者需根據任務複雜度判斷是否值得使用更高效能、更高成本的模型。

5. **開發者資源**：本文可能包含具體的選型流程圖或決策框架，幫助開發者在不同應用場景（聊天機器人、程式輔助、資料分析等）中做出最佳選擇。
