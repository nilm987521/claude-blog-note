## 重點摘要

1. **正式 GA 上線**：自 2026 年 6 月 29 日起，Claude 模型在 Microsoft Foundry（架設於 Azure）正式進入全面上市（Generally Available）階段，結束預覽期。
2. **可用模型**：Claude Opus 4.8 與 Claude Haiku 4.5 透過 Messages API 提供，支援提示快取（prompt caching）、擴展思考（extended thinking）及工具串流（tool streaming）等核心功能，適合程式開發、代理工作流程與複雜推理任務。
3. **兩種部署方式**：使用者可選擇「Azure 托管」（利用現有 Azure 身分認證、帳單與治理機制，支援美國資料區域）或「Anthropic 托管」（原 Foundry Preview，可取得完整 API 功能與更多模型選項）。
4. **Azure 原生整合**：Claude 與現有 Azure 身分驗證、網路及治理控制深度整合，單一發票結算，符合 Microsoft Enterprise Agreement 的客戶可將 Claude 用量計入 Azure 承諾額度。
5. **高效能硬體**：Claude 模型在 NVIDIA GB300 Blackwell Ultra GPU 上運行，提供企業級效能與可靠性。

## 重要公告

- **GA 里程碑**：Claude 在 Microsoft Foundry 正式 GA，代表企業可放心投入生產環境部署，不再受預覽版限制。
- **新模型上架**：Claude Opus 4.8 與 Claude Haiku 4.5 現已可透過 Microsoft Foundry 取用，滿足從輕量到高效能的不同需求。
- **資料落地合規**：支援美國資料區域（US data zone），協助有資料主權需求的企業符合法規要求。
- **企業帳務整合**：Claude 用量可計入 Microsoft Azure 企業協議承諾，簡化採購與財務管理流程。
