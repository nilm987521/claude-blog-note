## 重點摘要

1. **Claude Marketplace 大規模擴充**：Anthropic 在 Claude Marketplace 新增了多家合作夥伴的 Agents 與產品，涵蓋安全、開發者基礎設施、創意行銷及生產力四大領域，合作夥伴總數已超過 25 家。

2. **安全工具新增**：新上架的安全類產品包含 Chainguard Harness（在隔離環境中建構並測試應用程式漏洞）、Checkmarx One（結合規則式分析與 AI 推理排查程式碼漏洞）、Cyera Agent Guardian（追蹤 Claude 部署並對提示和工具呼叫執行政策）、Rubrik Code Guardian（審查多步驟攻擊路徑）及 Tanium Cloud（提供端點可視性與漏洞修補）。

3. **開發與創意工具**：開發基礎設施方面新增 Datadog Agent Observability（追蹤 Agent 執行並建議最佳化方案）與 Netlify Enterprise（部署至全球邊緣網路）；創意行銷工具新增 AirOps（AI 搜尋策略平台）、Runway（影片與圖像生成編輯）及 Webflow（網站建構與管理）。

4. **生產力工具整合**：生產力類新增 Asana AI Teammates（具有範圍權限的預建 Agents）、Glean（串聯公司知識與工作流程）、monday agents（在看板與文件中運作的 Agent）及 Zoom Agentic Search（在 Claude 內回答問題並具備權限感知結果）。

5. **企業費用整合方案**：符合資格的企業客戶可將已承諾的 Anthropic 消費額度應用於合作夥伴解決方案，讓一份合約同時涵蓋 Claude 本身與第三方合作產品，簡化採購流程。

## 重要公告

- **新模型**：無
- **新功能（Claude 本身）**：無
- **價格變動**：無（企業客戶可用已承諾額度購買合作夥伴產品，屬費用整合機制，非定價調整）
