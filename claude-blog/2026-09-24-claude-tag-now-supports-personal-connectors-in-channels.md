# Claude Tag 現在支援頻道中的個人連接器

**文章網址：** https://claude.com/blog/claude-tag-now-supports-personal-connectors-in-channels

## 重點摘要

1. **個人連接器支援：** Claude Tag 現在允許使用者在 Slack 頻道中使用與其個人帳號綁定的連接器（如日曆、雲端儲存、CRM、部署系統等），不再僅限於管理員控制的共享連接器。

2. **隱私控制機制：** 使用者可自行決定資訊的呈現方式，並可在發布回應前先行審核。「自動模式」下，除非 Claude 偵測到敏感內容，否則將自動發布回覆。

3. **管理員治理彈性：** 管理員可選擇提供代理人身份下的共享工具、將頻道成員限制為僅使用個人連接器以實現角色型存取控制，或依工具逐一決定策略。

4. **活動日誌分離：** 透過個人連接器進行的操作，會以使用者帳號記錄在該工具的日誌中，與頻道服務帳號的活動分開追蹤。

5. **推出計畫：** 首先在 Team 方案推出，Enterprise 方案隨後跟進；使用者無需預先安裝，Claude 會在首次使用時於對話串中請求授權。

## 重要公告

- 此更新使 Claude Tag 在協作場景中更具彈性，允許存取無法提供給整個頻道的敏感資源。
- 頻道自有連接器仍為排程例行任務與無人值守操作所必需。
