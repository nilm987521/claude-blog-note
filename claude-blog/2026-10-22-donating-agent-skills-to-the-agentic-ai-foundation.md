# 將 Agent Skills 捐贈給 Agentic AI Foundation

**文章網址：** https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation

## 重點摘要

1. **捐贈標準**：Anthropic 將 Agent Skills 開放標準捐贈給 Linux Foundation 旗下的 Agentic AI Foundation（AAIF），治理模式與先前捐出的 MCP 相同，由中立機構管理，讓社群參與標準未來方向的決定。

2. **技能是什麼**：Agent Skills 以一個資料夾為單位，內含 SKILL.md 檔案，用來教 AI agent 特定任務或領域的知識與流程，可附上腳本與參考資料。

3. **採用規模**：自 2025 年 12 月發布以來，已有超過 70 個 agent 平台整合（包括 ChatGPT、Cursor、GitHub Copilot 與 VS Code），約 100 萬個技能發布，安裝次數接近 2.8 億次。

4. **捐贈範圍**：包括 Agent Skills 名稱與標誌、GitHub 組織及 agentskills.io 網域。不加入 AAIF 的平台仍可繼續使用或貢獻此標準。

5. **後續規劃**：由 Anthropic、Google、OpenAI 等公司工程師以個人身分維護，Lead Maintainers 為 David Soria Parra 與 Mahesh Murag。後續將推出版本化發布、正式提案流程，以及撰寫和安裝技能的安全指引。

## 重要公告

- Agent Skills 開放標準正式移交 AAIF 治理，進一步強化其跨平台互通性與社群主導的發展方向。
