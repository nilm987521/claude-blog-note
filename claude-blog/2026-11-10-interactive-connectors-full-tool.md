## 文章資訊

**原文網址：** https://claude.com/resources/articles/interactive-connectors-full-tool

## 重點摘要

1. **全工具視圖（Full Tool View）**：第三方應用現可在對話旁以全工具視圖或全螢幕模式開啟，使用者可隱藏對話區或切換到全螢幕；支援的工具如 Confluence 和 Notion，可顯示完整編輯器並登入使用者自己的帳號。
2. **Claude 直接操作開啟的工具**：Claude 可在你正在查看的頁面、表格或檔案中直接進行編輯，使用者以核准連接器操作的相同方式來核准變更，修改內容會即時呈現。
3. **直接存取功能**：使用者可不需撰寫提示就直接開啟已連接的工具，然後從同一畫面向 Claude 尋求協助。
4. **釘選功能**：常用工具可釘選至側邊欄和「+」選單，與 Artifacts 並排顯示，方便快速存取。
5. **技術基礎與首批合作夥伴**：互動連接器建構於 MCP Apps 之上（Model Context Protocol 的開放擴充），目前已支援 Asana、Canva、Carta、Dropbox、monday.com、Adobe、Atlassian、Box、HubSpot、Notion、Figma、Harvey 和 Shopify 等合作夥伴工具。

## 重要公告

- **MCP Apps 開放預覽**：互動連接器底層的 MCP Apps 功能現處於公開預覽（Public Preview）階段，開發人員可參閱相關文件來建構支援此功能的整合。
- **適用對象**：此功能正在逐步推出至所有方案的網頁版和 Claude 桌面應用程式。管理員需更新帳號或由組織啟用，才能讓員工使用此功能。
