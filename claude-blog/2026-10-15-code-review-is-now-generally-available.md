# Code Review is now generally available

**文章網址：** https://claude.com/resources/articles/code-review-is-now-generally-available

## 重點摘要

1. **正式上線：** Claude Code 的 Code Review 功能已從研究預覽版正式上線，現可供 Claude Team 和 Enterprise 組織使用，不需開發者額外設定，安裝 GitHub App 後即可自動對新的 Pull Request 執行審查。

2. **速度大幅提升：** 大多數審查完成時間縮短約 3 倍，從約 20 分鐘降至 6–10 分鐘，大幅改善開發者的等待體驗。

3. **審查品質優化：** 找到的問題描述清晰簡潔，包含問題說明、觸發條件及修復建議，有助開發者快速理解並修正。

4. **可調整審查深度：** 管理員可為每個 Repository 分別設定 Quick、Standard（預設）或 Deep 三種審查深度，依需求彈性調整。

5. **Enterprise 優惠：** 符合資格的 Claude Enterprise 組織可在 2027 年 1 月 15 日前申領至少 $10,000 的 Code Review 使用額度（Credits），領取後 30 天內有效。

## 重要公告

- **新功能正式發布：** Code Review 正式 GA（Generally Available），不再是實驗性功能。
- **Enterprise 推廣活動：** 提供最少 $10,000 Credits 的限時優惠，鼓勵企業客戶採用。
- **管理員設定流程：** 於 Claude Code 設定中啟用 Code Review、安裝 GitHub App，並選擇要審查的 Repository。
