# JPMorganChase 將 Claude Code 擴展至更多員工

**文章網址：** https://claude.com/resources/articles/jpmorganchase-expands-claude-code

## 重點摘要

1. **超越工程師範疇**：JPMorganChase 將 Claude Code 的使用從工程師擴展至全公司更多員工，包括產品團隊、風險與合規人員，以及計畫規劃人員，Claude Code 在公司的容器化開發平台 Devspace 中的受控環境內執行。

2. **多部門應用場景**：資產與財富管理部門的工程團隊將其納入開發工作流程，表示在變更推送至客戶端前能進行更嚴格的測試；基礎設施團隊則用於監控、告警與根本原因分析；資安團隊利用前沿模型更快速地找出與修復漏洞。

3. **自建代理人生態**：工程師開始建立自己的代理人工具，例如 Pull Request 審查工具和自我修復工具，並在內部分享最佳實踐，形成企業內的 AI 工具共享文化。

4. **嚴格的安全管控**：代理人不直接存取員工憑證或內部系統，存取權限分階段擴展，新模型須通過公司的核准程序。每項變更都有自動化測試與閘門把關，員工對生產環境的變更仍須負責。

5. **相關產品連結**：文章也提及上個月宣布的連接器，將稅務感知的投資組合過渡分析功能整合至 Claude for Financial Advisors，進一步拓展金融服務領域的 AI 應用。

## 重要公告

- JPMorganChase 大規模擴展 Claude Code 企業部署，從工程師延伸至跨部門員工
- 展示金融業在嚴格安全管控下導入 AI 編碼工具的成功模式
- 與 Claude for Financial Advisors 的投資組合分析連接器協同推進金融 AI 生態布局
