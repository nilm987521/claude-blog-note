# Claude Fable 5.2 與 Mythos 5.2

**文章網址：** https://www.anthropic.com/claude-fable-and-mythos-5-2

## 重點摘要

1. **模型定位與差異**：Fable 5.2 與 Mythos 5.2 來自同一個基礎模型。Fable 內建較強的網路安全與生物安全防護，對所有使用者開放；Mythos 則提供給通過審核的組織，適合更高風險的技術研究場景。Anthropic 建議日常任務仍以 Opus 5.5 為主，較複雜或開放性的技術工作再切換到 Fable 或 Mythos。

2. **主要能力提升**：整體表現在多數評測上領先 Opus 5.5。程式設計方面，Anthropic 內部超過 90% 的合併程式碼已由 Claude 撰寫；一個關鍵服務從 Python 遷移到 Rust 後，啟動速度快約 26 倍；一名工程師讓模型在八天內透過一千多個子代理，從零開發出可開機的作業系統原型。

3. **科學與工程突破**：協助解決兩個黑洞物理的開放問題、以新方法預測病毒衣殼結構（34 個中準確模擬 28 個），並在約 30 小時內完成費馬最後定理的形式化證明。硬體設計方面，模型設計並製作出三款可運作的電子裝置。

4. **價格與速度**：標準定價為每百萬輸入 token 8 美元、輸出 40 美元。輸出速度比 5.1 快約 30%。快速模式最高可加速 2.5 倍，定價為每百萬輸入 16 美元、輸出 80 美元。

5. **安全與可用性**：反蒸餾防護大幅強化，可將蒸餾者收集的資料減少 90%–99%。網路與生物安全分類器的誤擋次數比 5.1 減少約 55%。模型已在主要雲端平台上線，API 模型名稱為 `claude-fable-5-2`。Enterprise Frontier Safeguards 目前處於私人測試階段。

## 重要公告

- **新模型發布**：Claude Fable 5.2 與 Claude Mythos 5.2 正式上線，API ID 為 `claude-fable-5-2`
- **定價**：標準版每百萬輸入 token $8 / 輸出 $40；快速模式每百萬輸入 $16 / 輸出 $80
- **速度**：輸出速度比 5.1 提升約 30%，快速模式最高加速 2.5 倍
- **Mythos 5.2** 需透過網路安全或生物醫學驗證計畫申請使用
- **Enterprise Frontier Safeguards** 進入私人測試（零資料保留相容）
