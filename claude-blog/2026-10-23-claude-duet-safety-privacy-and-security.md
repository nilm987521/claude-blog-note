# Claude Duet Safety, Privacy, and Security

**文章網址：** https://claude.com/resources/articles/claude-duet-safety-privacy-and-security

**發布日期：** 2026 年 10 月 23 日

## 重點摘要

1. **重要操作需使用者確認**：在 Claude Duet 發送敏感訊息、付款或刪除任何內容前，都會顯示操作內容、目標及完整細節（含所有收件人），並等待使用者確認。系統額外設有一個獨立的自動化分類器（改自 Claude Code 的自動模式分類器）驗證每個操作是否符合使用者意圖，防止網頁中的隱藏指令影響操作。部分操作即使使用者同意也被明確禁止，包括交易證券、在帳戶間轉移資金及存取他人帳戶。

2. **發送前過濾敏感資訊**：獨立的分類器會檢查每則對外訊息，並將私人資訊分為兩層：第一層「永不分享」包含登入憑證、完整卡號/銀行帳號及身分證號碼；第二層涵蓋健康與財務等其他私人細節，需明確同意才可分享。若訊息被攔截，系統會提供去除敏感內容的修改版本供使用者確認。

3. **憑證與密碼完全隔離於模型之外**：Claude Duet 永遠無法取得使用者的密碼、Cookie 或登入憑證，也無法將其儲存於記憶中。網站要求密碼時，使用者在 Claude 應用程式的表單中輸入，表單以一次性金鑰加密後僅傳至雲端瀏覽器機器，模型從不接觸明文。未來將支援 1Password 整合，讓每次憑證使用都需在 1Password 中確認。

4. **瀏覽器獨立隔離並公開身分**：每個瀏覽器在獨立的雲端虛擬機器中運行，代理只能使用固定指令集（如開啟頁面、點擊、輸入），且無法讀取 Cookie。Claude Duet 使用獨特的 User-Agent 標頭並公開其瀏覽 IP 位址，讓網站能識別其身分；部分大型網站在上線前已選擇封鎖。

5. **透明監督與安全測試**：使用者可透過任務清單查看每個任務的詳細頁面，並可在任務執行中途介入調整。Anthropic 安全團隊進行了多種情境評估（無害、注入指令、誘使超越授權），紅隊測試了資料洩漏與未授權操作，並委託外部滲透測試公司審查。Claude Duet 亦納入 Anthropic 在 HackerOne 上的公開漏洞獎勵計畫。目前為研究預覽版，確認機制、登入方式與敏感資訊檢查仍在持續改進中。

## 重要公告

- **Claude Duet 安全架構詳細說明**：首次公開 Claude Duet 的完整安全設計，包含購買時使用一次性虛擬卡（如 Link）保護真實卡號
- **雙層敏感資訊分類機制**：建立「永不分享」與「需同意才分享」的分級保護體系
- **即將推出 1Password 整合**：強化憑證管理安全性
- **目前為研究預覽版**：Anthropic 持續優化相關安全機制
