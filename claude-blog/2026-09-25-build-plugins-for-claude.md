- **分類**：Product announcements

## 重點摘要

1. **新推出目錄提交入口**：付費版 Claude 開發者現可透過專屬入口提交外掛，流程涵蓋從提交到上架的完整步驟，並內建自動驗證與安全掃描功能。

2. **兩種提交方式**：開發者可選擇提交單一指向遠端伺服器的 MCP 連接器，或提交包含 MCP 伺服器與技能的 GitHub 託管外掛套件。

3. **內建監控工具**：外掛上架後，開發者可取得使用分析數據，包含各產品介面的安裝數量、版本分佈，以及探索指標（如列表瀏覽次數與搜尋關鍵字）。

4. **支援 MCP 2.0**：Claude 現已支援最新版模型情境協定（Model Context Protocol），新增 MCP Apps 互動 UI 及企業管理驗證（Enterprise Managed Auth）等 OAuth 簡化擴充功能。

5. **統一外掛生態系**：外掛成為第三方開發者擴展 Claude 的主要方式，技能（skills）與連接器（connectors）仍作為基礎元件，未來可逐步升級為正式外掛。

## 重要公告

- **目錄提交入口正式開放**：開發者現可透過簡化的發布與分析體驗，將外掛推廣給數百萬 Claude 使用者。
- 這標誌著 Claude 外掛生態系走向統一化，讓第三方開發者有更完整的工具鏈來建構、發布及追蹤外掛效能。
