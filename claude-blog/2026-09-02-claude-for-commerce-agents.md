# Building Commerce Agents with Claude

**文章網址：** https://claude.com/blog/claude-for-commerce-agents

## 重點摘要

1. **商務代理藍圖正式發布**：Anthropic 推出以 Claude 為核心的商務代理藍圖，包含工程團隊快速建立商務代理所需的全套框架、模式與安全防護措施，最快數天即可上線。

2. **廣泛的企業採用**：全球最大的零售商、市集、電商平台與旅遊公司已採用 Claude 建立商務代理，企業客戶包括 Shopify、Priceline 等，讓消費者能以自然語言搜尋、比較並完成購物。

3. **雙軌代理架構**：藍圖提供購物代理（shopping agent）與商家代理（merchant agent）兩種參考實作，分別服務消費者端與賣家端的需求，適用於零售、旅遊、電信及票務等平台。

4. **Claude Code 插件整合**：隨附 Claude Code 插件，讓開發者可直接在開發環境中快速啟動並測試商務代理，降低導入門檻。

5. **AI 輔助商務新典範**：商務代理使消費者能以自然語言描述需求，讓 AI 代為搜尋、篩選、比較商品並完成交易，大幅改變傳統電商體驗。

## 重要公告

- **新功能：商務代理藍圖**：正式提供可商用的商務代理建置方案，配合《商務代理剖析指南》技術文章（claude.com/blog/the-anatomy-of-effective-commerce-agents）一同發布。
- **企業夥伴**：Shopify、Priceline 等頭部企業已部署 Claude 商務代理至正式環境。
