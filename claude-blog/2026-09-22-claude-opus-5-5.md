## 重點摘要

1. **新模型發布**：Anthropic 於 2026 年 9 月 22 日推出 Claude Opus 5.5，效能媲美 Claude Fable 5.1，整體任務成本比 Opus 5 降低 40%，輸出速度提升 30%。

2. **效能表現**：在多項基準測試中名列前茅，包括 Terminal-Bench 4.0（66.4%）、GDPval-AA v2.1（1846 Elo）、OSWorld 2.0（81.8% partial）、CursorBench 4.0（57.8%），並在相似效能下僅需 GPT-6 Astra 約 20–40% 的費用。

3. **定價調整**：輸入 token 降為 $4/M（原 $5），輸出 token 降為 $20/M（原 $25），快取讀取大幅降為 $0.20/M（原 $0.50），降幅達 60%。

4. **安全性強化**：在 Anthropic 自動行為審計中得分最高，提示注入攻擊抵禦能力提升，邊界規避嘗試減少 85%；每次執行動作前均進行分類器審查，並新增開源沙箱供安全團隊稽核。

5. **即時上線與後續計畫**：即日起可透過 Claude Platform（`claude-opus-5-5`）、AWS、Google Cloud 及 Microsoft Azure 使用；數週內將推出 Claude Sonnet 5.5 與 Claude Haiku 5.5。

## 重要公告

- **新模型**：Claude Opus 5.5 正式發布，為 Claude 5.5 家族的旗艦模型。
- **價格變動**：全面降價，輸入/輸出各降 20%，快取讀取降 60%。
- **速度提升**：輸出速度比 Opus 5 快 30%；Faster mode 最高可達 2.5 倍速（$8 輸入，$40 輸出 per million tokens）。
- **Pro/Max/Team/Enterprise 方案**：使用上限提升，並新增速率限制重置功能。
- **合規新增**：整合浮水印功能以符合歐盟 AI 法規要求。
- **Thinking mode 不可關閉**：作為安全功能，2026 年 8 月 31 日後建立的 API 帳號保留思考防蒸餾保護。
