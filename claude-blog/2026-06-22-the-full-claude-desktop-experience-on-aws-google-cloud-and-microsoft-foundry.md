## 重點摘要

1. **完整 Desktop 體驗擴展至三大雲端平台**：透過 AWS、Google Cloud 及 Microsoft Foundry 使用 Claude Desktop 的企業用戶，現可享有完整的 Desktop 體驗——對話（Chat）、Claude Cowork 與 Claude Code 整合於單一應用程式，此前僅提供 Cowork 與 Code 功能。
2. **企業 IT 管理功能強化**：IT 團隊可透過每位使用者的 SSO（單一登入）、MDM 政策範本、離線安裝程式選項，以及可完全在裝置端運行的 M365 連接器，在組織內全面部署 Claude Desktop。
3. **資料主權與隱私控制**：推論運算（inference）在客戶自行設定的雲端區域（region）上執行，對話記錄儲存於本地端，組織可自行掌控資料連接器所存取的端點，以及 Anthropic 接收的彙整遙測資料。
4. **跨產品保持推論於自有環境**：IT 團隊現可在 Chat、Cowork 及 Code 等所有產品中，將推論運算保持在自有雲端環境內，滿足企業對資料落地與合規的需求。
5. **重大功能落差補足**：此更新填補了企業雲端部署與一般 Claude Desktop 之間的功能差距，企業用戶在保有資料控制的同時，可獲得與消費端相同的完整對話體驗。

## 重要公告

- **全面對話功能開放**：企業雲端平台用戶終可在自有雲端基礎架構上使用完整的 Claude 對話介面，不再受限於 Cowork 與 Code。
- **企業部署套件**：新增 SSO 整合、MDM 政策範本及離線安裝程式，大幅簡化大規模組織部署流程。
- **M365 連接器本地化**：Microsoft 365 連接器可選擇完全在裝置端運行，進一步強化資料隱私保護。
