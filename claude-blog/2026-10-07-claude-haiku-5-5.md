## 文章資訊

**來源：** https://www.anthropic.com/claude-haiku-5-5
**發布日期：** 2026-10-07

## 重點摘要

1. **全新最快小型模型**：Claude Haiku 5.5（模型 ID：`claude-haiku-5-5`）是 Anthropic 迄今最便宜、最快速的小型模型，首款支援可調整 effort 設定的 Haiku 系列模型，適合高量、低成本工作（如摘要、資料庫查詢、分類）及即時客服應用。

2. **大幅效能提升**：OSWorld 2.1 得分從 Haiku 4.5 的 15.7% 躍升至 72.4%；Terminal-Bench 4.0 得分從 0.0% 提升至 39.2%；Humanity's Last Exam 無工具得分為 45.9%。HubSpot、Box、AlphaSense 等客戶均回報速度與準確度顯著提升。

3. **大幅降價**：輸入定價 $0.10/M tokens、輸出 $0.50/M tokens（100k tokens 以下），相較 Haiku 4.5（$1.00/$5.00）平均降低約 75%；超過 100k tokens 的提示為 $0.50 輸入/$2.50 輸出。

4. **安全性改善**：相比 Haiku 4.5 大幅提升對齊品質；網路安全防護比 Haiku 4.5 更嚴格（但不及 Sonnet 5.5），生物學防護與 Sonnet 5、Sonnet 5.5、Opus 5 齊平，封鎖滲透測試等攻擊者導向技術。

5. **同步公告**：Sonnet 5.5 快取讀取價格減半至 $0.10/M tokens，大幅降低代理任務成本約 20%；Max 與 Team 訂閱者將獲得每月 API 積分；Haiku 5.5 即日起可於 AWS、Google Cloud、Microsoft Azure 使用，Python 與 TypeScript SDK 加入電腦使用及瀏覽器使用的 beta 支援。

## 重要公告

- **新模型上線**：Claude Haiku 5.5 正式發布，支援 computer use 與 browser use（beta）
- **降價 75%**：相較前代 Haiku 4.5，平均降低 75% 費用
- **Sonnet 5.5 快取讀取降價**：快取讀取從 $0.20 降至 $0.10/M tokens
- **訂閱方案增益**：Max 與 Team 訂閱者每月獲得 API 積分
