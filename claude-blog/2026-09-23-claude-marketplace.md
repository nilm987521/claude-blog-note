## 重點摘要

1. **Claude Marketplace 正式推出**：整合了外掛程式（plugins）、連接器（connectors）、AI 代理（agents）、產品及服務合作夥伴，打造統一的探索與採購平台，讓客戶更容易找到適合的工具，也讓開發者更容易接觸到 Claude 用戶。

2. **超過 2,000 個連接器與外掛程式**：涵蓋 Atlassian、Google、Microsoft、Notion、Salesforce 等主流平台，企業用戶可直接在 Claude 工作流中串接這些服務。

3. **商業採購整合**：企業可透過已承諾的 Anthropic 預算，直接購買 CrowdStrike、Cursor、Harvey、Legora、Lovable、Snowflake 等廠商提供的 Claude 驅動產品與代理服務，簡化採購流程。

4. **三種合作夥伴上架方式**：
   - **連接器/外掛程式**：基於 MCP（Model Context Protocol）和 Agent Skills 標準開發
   - **產品**：申請上架 Claude 驅動的代理或軟體，讓客戶可用承諾預算購買
   - **服務**：加入 Claude Partner Network，出現在市場目錄（包含 Accenture、BCG、Deloitte 等顧問公司）

5. **特色合作案例**：CodeRabbit、Power Digital 和 ThoughtSpot 透過 Marketplace 將 Anthropic 承諾預算延伸至 Vercel 和 Snowflake 等互補服務，展示了平台的靈活採購價值。

## 重要公告

- **新功能/平台**：Claude Marketplace 正式上線，這是 Anthropic 在企業生態系整合方面的重大里程碑，統一了外掛程式、代理、產品與服務合作夥伴的探索與採購入口。
- **生態系擴張**：已有超過 2,000 個連接器，並納入 Atlassian（Teamwork Graph 整合）、CrowdStrike（Falcon 平台）、Hebbia（投資研究）、Legora（法律 AI）等知名合作夥伴。
