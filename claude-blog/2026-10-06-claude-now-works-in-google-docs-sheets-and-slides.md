## 文章資訊

## 重點摘要

1. **公測上線**：Claude for Google Workspace 現已在所有付費方案中進入公測階段，透過新的附加元件與連接器，無縫整合 Google 文件、試算表和簡報。

2. **Google 文件整合**：Claude 在側邊欄中運作，可直接在文件內編輯文字，提供修改建議卡片讓使用者審核，無需在應用程式間切換。

3. **Google 試算表功能**：可撰寫公式、建立樞紐分析表、製作圖表，並能透過 Python 進行資料合併與清理後將結果返回試算表。

4. **Google 簡報功能**：能依照現有簡報版面配置和主題建立新投影片，並自動偵測重疊元素或文字可讀性問題。

5. **企業版特色**：企業方案用戶可享有 Compliance API 整合、客戶自管加密金鑰，以及透過 OpenTelemetry 的稽核匯出支援。

## 重要公告

- **新功能：** Claude for Google Workspace 公測版本正式對所有付費方案開放
- 支援兩種操作模式：「編輯前詢問」（預設）和「接受所有編輯」（自主操作模式）
- 可透過 Google Workspace Marketplace 安裝，企業管理員可透過 Google Admin Console 部署
- 繼承使用者 Claude 帳戶中已設定的連接器、技能和企業管控設定
