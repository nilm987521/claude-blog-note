## 重點摘要

1. **效能大幅提升**：Claude Sonnet 5.5 在程式碼基準測試 Terminal-Bench 4.0 上達到 70.6%，相較前代 Sonnet 5 的 10.3% 有顯著躍進，同時在知識工作基準測試上幾乎追平 Opus 5.5。

2. **速度與成本更優化**：輸出速度比前代快 30% 以上；雖然每百萬 Token 定價與 Sonnet 5 相同（輸入 $2、輸出 $10），但因完成任務所需 Token 更少，實際費用可節省最多 30%。

3. **代理程式任務能力突出**：在長時程的自主代理任務（Agentic Tasks）表現卓越，並成為首個僅憑截圖就能完成《寶可夢 紅》遊戲的 Sonnet 系列模型。

4. **安全防護同步強化**：網路安全防護能力比肩 Opus 5.5，生物安全防護延續 Sonnet 5 水準，並新增防止大規模能力提取的蒸餾（Distillation）防禦機制。

5. **跨平台即時可用**：使用模型識別碼 `claude-sonnet-5-5`，現已在 AWS、Google Cloud、Azure 及 Claude Platform 上全面開放。

## 重要公告

- **新模型發布**：Claude Sonnet 5.5 正式推出，定位為日常工作的高 CP 值選擇，可與處理複雜任務的 Opus 5.5 相互搭配。
- **定價不變，效率更高**：每 Token 定價維持不變，但實際任務成本因效率提升而降低約 30%。
