## 重點摘要

1. **重建設計系統匯入功能**：用戶可從 GitHub 倉庫、設計檔案或原始上傳匯入一個或多個設計系統，Claude Design 將使用已批准的元件進行構建，並在呈現前自動與設計系統核對，確保輸出完全符合品牌規範。
2. **與 Claude Code 深度整合**：可在 Claude Design 和 Claude Code 之間流暢切換並保持同步；在 Claude Code 中使用 `/design-sync` 可引入現有設計系統，設計完成後可直接交由 Claude Code 接手繼續開發，無需從截圖重頭開始。
3. **大幅擴展匯出目標**：除 PDF 和 PowerPoint 外，新增對 Adobe、Base44、Canva、Gamma、Lovable、Miro、Replit、Vercel 和 Wix 等平台的匯出支援，讓跨工具協作更加流暢。
4. **改善畫布編輯與企業管理控制**：新增直接在畫布上拖拽、調整大小和對齊元素的功能；企業管理員可批准並鎖定單一設計系統，確保全公司所有專案維持品牌一致性。
5. **優化 token 使用率**：大幅降低每次對話的平均 token 消耗並同時維持輸出品質，錯誤率也顯著下降；Claude Design 現在與聊天、Claude Cowork 和 Claude Code 共享使用限制，不再從獨立的較小配額中扣除。

## 重要公告

- **Claude Design 重大改版**：此次更新將 Claude Design 從早期聚焦於演示的工具，轉型為可用於日常工作的企業級設計系統合規平台，顯著提升與開發工作流程的整合深度及品牌一致性保障能力。
- **目前以 Beta 版提供**：Claude Design 目前在 Claude Pro、Max、Team 和 Enterprise 計劃中以 Beta 版形式提供，包含於訂閱費用內；Enterprise 用戶預設關閉，需由管理員在組織設定中啟用，且分享僅限組織內部。
