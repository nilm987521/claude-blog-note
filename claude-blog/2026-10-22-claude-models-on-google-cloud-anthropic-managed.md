# 完整的 Claude Platform 現已登陸 Google Cloud

**文章網址：** https://claude.com/blog/claude-models-on-google-cloud-anthropic-managed

## 重點摘要

1. **完整功能同步上線**：Anthropic 管理的服務正式在 Google Cloud 推出，新功能與測試版會與原生 Claude Platform 同日上線，Google Cloud 客戶不再落後。

2. **沿用既有帳號與計費**：可直接使用 Google Cloud IAM 憑證管理權限，透過單一 Google Cloud 帳單付費，用量計入既有的 Google Cloud 承諾消費額度。

3. **三大功能類別**：包含建構代理程式（Managed Agents 測試版、程式碼執行、電腦操作）、連接系統與知識（Files API、網路搜尋、MCP 連接器），以及降低成本的工具（提示快取與批次處理）。

4. **兩種部署路徑**：Anthropic 管理版（功能完整同步，Anthropic 為資料處理者）vs. Google 管理版（嚴格區域資料駐留需求，支援 Model Armor、Agent Engine 等 Google 原生整合）。

5. **Claude Console**：開發者可透過此環境管理與監控代理程式、追蹤用量與成本。

## 重要公告

- **Opus 5.5 快速模式正式推出**：輸出速度最高可達 2.5 倍，適合即時除錯與互動式代理程式，輸入每百萬 token 8 美元、輸出每百萬 token 40 美元。
- **可用模型**：Claude Fable 5.1、Opus 5.5、Sonnet 5.5 與 Haiku 5.5 皆已可用，新模型隨發布同步提供。
- **目前可用端點**：僅提供美國（US）與全球（Global）端點。
- **折扣注意**：既有折扣不可追溯套用，需事先聯繫 Anthropic 或 Google Cloud 業務代表。
