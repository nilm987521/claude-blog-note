## 文章資訊

- **來源**：Anthropic 新聞
- **網址**：https://www.anthropic.com/news/claude-opus-5
- **發布日期**：2026-07-24

## 重點摘要

1. **新模型發布**：Anthropic 正式推出 Claude Opus 5，定位為近旗艦級智能模型——在多項評測指標上接近旗艦模型 Fable 5 的表現，但定價僅為其一半。

2. **價格詳情**：Opus 5 定價為每百萬輸入 token $5、每百萬輸出 token $25，與前代 Opus 4.8 相同；相較之下，Fable 5 的定價為每百萬輸入 $10、每百萬輸出 $50。另有 Fast mode 可選，速度約快 2.5 倍，但費用加倍。

3. **效能表現**：Opus 5 在 ARC-AGI-3 上得分 30.2%，比次高競爭模型高出三倍；在困難程式設計任務上的表現約為 Opus 4.8 的兩倍；在代理編程、創新問題解決、知識工作、電腦操作及多學科推理等項目的評測上均優於 Opus 4.8。

4. **新功能：努力等級切換**：用戶可選擇低、中、高三種努力等級，控制模型在回答問題或完成任務時投入的計算資源，有助於在成本與效能之間靈活取捨。

5. **規格與可用性**：支援 1M token 上下文視窗（預設值與最大值相同）、128k 最大輸出、知識截止日期為 2026 年 5 月。即日起在 Claude API、Claude.ai、Claude Code 及 Claude Cowork 全面推出，並成為 Claude Max 的新預設模型，也是 Claude Pro 上最強的可用模型。

## 重要公告

- **新模型上線**：Claude Opus 5 正式發布，替換前代 Opus 4.8
- **定價不變**：保持與 Opus 4.8 相同的定價，但效能大幅提升
- **Fable 5 替代方案**：Opus 5 在多項基準測試上超越 Fable 5，同時僅需一半費用
- **預設模型異動**：Opus 5 成為 Claude Max 的新預設模型，取代原有配置
