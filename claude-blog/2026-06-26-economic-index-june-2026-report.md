## 重點摘要

1. **Claude Code 大量使用旗艦模型**：Claude Code 工作階段有 54% 由 Opus 模型提供服務，遠高於一般聊天與 Cowork 對話的 10%，顯示程式開發任務對高效能推理的需求更高；即使同樣使用 Sonnet，Claude Code 的自主性仍高出 0.26 分。

2. **AI 自主性與運算資源正相關**：高自主性任務（建立應用程式、網站、遊戲、簡報）消耗更多運算資源；低自主性任務（數學計算、翻譯、問答）消耗較少，兩者的中位數 token 用量隨自主性分數同步上升。

3. **Claude Code 展現顯著更高的 AI 自主性**：在幾乎所有輸出類型中，使用 Claude Code 比使用一般聊天或 Cowork 平均高出 0.53 分（1–5 分量表），說明產品選擇對自主性水準的影響可能比底層模型更顯著。

4. **「經濟基本要素」五大衡量維度**：報告持續採用任務複雜度、技能等級、使用目的（工作／教育／個人）、AI 自主性與任務成功率等五項指標，系統性追蹤 AI 對勞動市場的影響。

5. **首次大規模調查資料連結**：2026 年 4 月啟動的 Anthropic 經濟指數調查，透過隱私保護方法將約 9,700 名受訪者的問卷回應與 5 月中至 6 月初的使用資料相連結，多數受訪者預期未來一年 AI 將出現重大進展。

## 重要公告

- 本報告資料涵蓋 2026 年 4 月 10 日至 6 月 10 日之聊天與 Cowork 對話，以及同期 Claude Code 工作階段。
- 這是 Anthropic 經濟指數系列的第三份季度報告，前兩期分別為「Economic Primitives」（2026 年 1 月）與「Learning Curves」（2026 年 3 月）。
- 報告作者：Maxim Massenkoff、Eva Lyubich、Szymon Sacher、Zoe Hitzig、Shaoyi Zhang、Ryan Heller、Peter McCrory。
