# Claude for Government 正式全面開放

**文章網址：** https://claude.com/blog/claude-for-government-is-now-generally-available

## 重點摘要

1. **正式全面開放（GA）**：Claude for Government 從 2025 年 7 月的公開測試版正式進入全面可用階段，適用於美國聯邦及州政府機構，運作環境符合 FedRAMP High 認證要求。

2. **核心功能**：包括桌面整合（可直接存取機構檔案）、技能／插件／專案（支援備忘錄撰寫、RFP 審查、案件管理），以及 Claude Code 用於建置與現代化公共部門軟體系統。

3. **管理控制**：提供部門層級的支出分配、審計日誌（支援 ATO 流程）、自訂身分提供者（SSO）、SCIM 群組映射，以及在機構管理設備上的本地對話記錄。

4. **計費模式改變**：採用**無席位費用**的使用量計費模式，並支援硬性支出上限，方便各機構控管預算。

5. **後續擴展**：Claude Code CLI 與 Claude for Microsoft 365 正在透過相同的 FedRAMP High 環境推出早期存取計畫，管理控制一致。

## 重要公告

- **新功能**：Claude for Government 正式 GA，新機構可透過 claude.com/solutions/government 申請存取。
- **定價變動**：從席位制改為使用量計費（含硬性支出上限），並支援跨子機構的部門層級分配。
