## 重點摘要

1. **政府專屬部署上線：** Claude Code 與 Claude Cowork 現以公開測試版形式納入 Claude for Government Desktop，在 FedRAMP High 授權環境中提供服務，符合美國聯邦政府資安合規要求。

2. **兩大工具的政府應用場景：** Claude Code 協助公部門技術團隊建構與現代化支撐公共服務的軟體系統；Claude Cowork 讓機構員工能委派備忘錄撰寫、RFP 審查、案件管理及簡報製作等行政工作。

3. **資安與合規設計：** 對話歷史僅儲存在機構自管的本地裝置上，推論運算在 FedRAMP High 授權環境中進行，支援機構 ATO（授權使用）流程，並提供防篡改審計日誌。

4. **管理員控制功能：** 管理員可設定組態預設值，分配並控制各部門的 AI 支出額度；安全團隊可獲得防篡改的審計日誌與文件，支援合規審查。

5. **彈性計費方案：** 計劃辦公室可透過標準席位或自定義席位等級（含支出上限與模型限制）將 AI 費用與撥款資金綁定，適應政府預算管理需求。

## 重要公告

- **新功能（公開測試版）：** Claude Code 與 Claude Cowork 正式進入 Claude for Government Desktop
- **合規認證：** 服務在 FedRAMP High 授權環境中運行，適用於處理敏感政府數據的工作場景
